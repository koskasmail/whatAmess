
# current_program_path 

##### ver #1:

'''

Here is a complete, multi-package Java implementation that follows your exact requirements.

To organize this cleanly, the project uses four parts:

1. **`context` package**: A global context holder with getter/setter methods to store the base path accessibly across all packages.
2. **`onload` package (`OnloadMain`)**: Detects the running JAR's path and saves it to the global context.
3. **`logger` package (`AppLogger`)**: Uses the stored base path to create the `./logs/logs` directory and write/read logs.
4. **`Main` class**: The entry point that orchestrates the sequence.

### 1. The Global Context (`context.AppContext.java`)

This acts as the shared storage container using getter/setter methods so any package in your program can retrieve the base path.

```java
package context;

public class AppContext {
    private static String basePath;

    // Getter for the base path
    public static String getBasePath() {
        return basePath;
    }

    // Setter for the base path
    public static void setBasePath(String path) {
        basePath = path;
    }
}

```

---

### 2. The Onload Package (`onload.OnloadMain.java`)

This class finds the absolute path of the executing JAR (or IDE build directory) and plants it into the global context.

```java
package onload;

import context.AppContext;
import java.io.File;
import java.net.URISyntaxException;

public class OnloadMain {
    
    public static void loadPath() {
        try {
            // Get the directory of the currently running JAR/program
            File jarDir = new File(OnloadMain.class
                .getProtectionDomain()
                .getCodeSource()
                .getLocation()
                .toURI())
                .getParentFile();

            String currentPath = jarDir.getAbsolutePath();
            
            // Plant it in the global context (getter/setter style)
            AppContext.setBasePath(currentPath);
            
            System.out.println("[Onload] Successfully resolved and set base path: " + currentPath);

        } catch (URISyntaxException e) {
            System.err.println("[Onload] Failed to resolve JAR path: " + e.getMessage());
            e.printStackTrace();
        }
    }
}

```

---

### 3. The Logger Package (`logger.AppLogger.java`)

This package fetches the base path from the global context, builds the `./logs/logs` folder relative to it, and provides a globally accessible method to write logs.

```java
package logger;

import context.AppContext;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.time.LocalDateTime;

public class AppLogger {

    // Helper to resolve the exact log file path using the base path
    private static File getLogFile() {
        String basePath = AppContext.getBasePath();
        
        // Fallback if context wasn't initialized
        if (basePath == null) {
            basePath = System.getProperty("user.dir");
        }

        // Create target directory: <basePath>/logs/logs
        File logDir = new File(basePath, "logs" + File.separator + "logs");
        if (!logDir.exists()) {
            logDir.mkdirs();
        }

        return new File(logDir, "app_activity.log");
    }

    // Globally accessible method to write logs from anywhere in the program
    public static synchronized void writeLog(String message) {
        File logFile = getLogFile();
        try (PrintWriter writer = new PrintWriter(new FileWriter(logFile, true))) {
            String timestampedMessage = LocalDateTime.now() + " - " + message;
            writer.println(timestampedMessage);
            System.out.println("[Logger] Log written: " + timestampedMessage);
        } catch (IOException e) {
            System.err.println("[Logger] Error writing to log file: " + e.getMessage());
        }
    }
}

```

---

### 4. The Main Entry Point (`Main.java`)

This brings everything together inside the `main` method.

```java
import onload.OnloadMain;
import logger.AppLogger;

public class Main {
    public static void main(String[] args) {
        System.out.println("=== Application Starting ===");

        // Step 1: Call the onload package to initialize and plant the path
        OnloadMain.loadPath();

        // Step 2: Call the log package to write logs using that base path
        AppLogger.writeLog("Application started successfully.");
        AppLogger.writeLog("Testing global log package accessibility from Main.");

        System.out.println("=== Application Finished Execution ===");
    }
}

```

---

### How It Works When Executed:

1. When you package and run this as a JAR (e.g., `java -jar myapp.jar`), `OnloadMain.loadPath()` captures the directory containing `myapp.jar`.
2. It saves this path inside `AppContext`.
3. When `AppLogger.writeLog(...)` is called anywhere in your application, it pulls that base path and creates a folder structure **`[JAR-Location]/logs/logs/app_activity.log`**, successfully writing to it without trying to alter the read-only contents inside the JAR itself.
