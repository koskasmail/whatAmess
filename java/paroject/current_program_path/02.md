
##### 02

```
when finding the base folder of the executable jar/program create a folder called "root"
if not exist already and inside write all the logs, for example if jar file exists in "c:\jars\this.jar" create a folder "c:\jars\root" that inside create the logs file.
in the main folder create a config.jar, and write all of the paths in key:value style 
Here is the updated multi-package implementation that creates the `"root"` folder inside the JAR's base directory for logs, and generates a key:value configuration file in the main folder.
*(Note: Since a `.jar` file is a compiled binary archive, configuration data with key:value pairs is standardly stored in a text-based properties file like `config.properties` rather than a `.jar` file).*
```

### 1. Global Context (`context.AppContext.java`)

Updated to store both the base path and the newly created `root` path globally.

```java
package context;

public class AppContext {
    private static String basePath;
    private static String rootPath;

    public static String getBasePath() {
        return basePath;
    }

    public static void setBasePath(String path) {
        basePath = path;
    }

    public static String getRootPath() {
        return rootPath;
    }

    public static void setRootPath(String path) {
        rootPath = path;
    }
}

```

### 2. The Onload Package (`onload.OnloadMain.java`)

This finds the JAR's location, creates the `root` folder if it doesn't exist, plants the paths in the context, and writes the `config.properties` file in the main folder with key:value pairs.

```java
package onload;

import context.AppContext;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.net.URISyntaxException;

public class OnloadMain {
    
    public static void loadPath() {
        try {
            // 1. Get the directory where the running JAR is located (e.g., C:\jars)
            File jarDir = new File(OnloadMain.class
                .getProtectionDomain()
                .getCodeSource()
                .getLocation()
                .toURI())
                .getParentFile();

            String basePath = jarDir.getAbsolutePath();
            AppContext.setBasePath(basePath);

            // 2. Create the "root" folder inside the main folder if it doesn't exist (e.g., C:\jars\root)
            File rootDir = new File(jarDir, "root");
            if (!rootDir.exists()) {
                boolean created = rootDir.mkdirs();
                if (created) {
                    System.out.println("[Onload] Created 'root' folder at: " + rootDir.getAbsolutePath());
                }
            }
            String rootPath = rootDir.getAbsolutePath();
            AppContext.setRootPath(rootPath);

            // 3. Create config.properties in the main folder with key:value paths
            File configFile = new File(jarDir, "config.properties");
            try (PrintWriter writer = new PrintWriter(new FileWriter(configFile, false))) {
                writer.println("base_path=" + basePath);
                writer.println("root_path=" + rootPath);
                writer.println("log_file_path=" + new File(rootDir, "app_activity.log").getAbsolutePath());
                System.out.println("[Onload] Config file written to: " + configFile.getAbsolutePath());
            }

        } catch (URISyntaxException | IOException e) {
            System.err.println("[Onload] Error during initialization: " + e.getMessage());
            e.printStackTrace();
        }
    }
}

```

### 3. The Logger Package (`logger.AppLogger.java`)

Pulls the `root` path from the global context and writes logs directly inside the `root` folder.

```java
package logger;

import context.AppContext;
import java.io.File;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.time.LocalDateTime;

public class AppLogger {

    private static File getLogFile() {
        String rootPath = AppContext.getRootPath();
        
        if (rootPath == null) {
            rootPath = System.getProperty("user.dir") + File.separator + "root";
        }

        File rootDir = new File(rootPath);
        if (!rootDir.exists()) {
            rootDir.mkdirs();
        }

        return new File(rootDir, "app_activity.log");
    }

    public static synchronized void writeLog(String message) {
        File logFile = getLogFile();
        try (PrintWriter writer = new PrintWriter(new FileWriter(logFile, true))) {
            String timestampedMessage = LocalDateTime.now() + " - " + message;
            writer.println(timestampedMessage);
            System.out.println("[Logger] Written to root: " + timestampedMessage);
        } catch (IOException e) {
            System.err.println("[Logger] Error writing to log file: " + e.getMessage());
        }
    }
}

```

---

### 4. Main Entry Point (`Main.java`)

```java
import onload.OnloadMain;
import logger.AppLogger;

public class Main {
    public static void main(String[] args) {
        System.out.println("=== Application Starting ===");

        // Step 1: Run Onload to set up paths, create the 'root' folder, and write config.properties
        OnloadMain.loadPath();

        // Step 2: Write log entries into the root folder
        AppLogger.writeLog("Application initialized successfully.");
        AppLogger.writeLog("All paths successfully mapped and stored in global context.");

        System.out.println("=== Application Execution Complete ===");
    }
}

```

### What this creates on your file system:

If your JAR is located at `C:\jars\this.jar`, running it will automatically generate:

1. **`C:\jars\root\`** (Directory created if missing)
2. **`C:\jars\root\app_activity.log`** (Where all logs are written)
3. **`C:\jars\config.properties`** (Main folder config file containing:)
```text
base_path=C:\jars
root_path=C:\jars\root
log_file_path=C:\jars\root\app_activity.log

```
