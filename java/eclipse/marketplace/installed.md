
# installed 

### Installed solutions list (plugins)

> To view your installed solutions list (plugins) and remove them in Eclipse,
>> follow these steps:

### View Installed List

1. Open **Eclipse**.
2. click the Menu Bar **Help** > **"About Eclipse IDE"**
3. click the Installation Details button (located near the bottom-left corner).
4. search and select the installed software/solution and click on Update/Uninstall/properties/close button (located on bottom of window). 

-----

### How to Remove / Uninstall Plugins

##### eclipse menu remove
1. Open **Eclipse**.
2. click the Menu Bar **Help** > **"About Eclipse IDE"**
3. click the Installation Details button (located near the bottom-left corner).
4. search and select the installed software/solution and click on Uninstall button (located on bottom of window). 

##### Manual Removal (For "Dropins" or manual JAR placement)

> If a plugin was installed by manually copying files into a folder:

1. Close Eclipse.
2. Navigate to your Eclipse installation directory on your computer. 
3. Open the `dropins` folder or the `plugins` folder.
4. Delete the files or folders associated with the target plugin.
5. Restart Eclipse.
* *TIP*: *Verification:* Launch Eclipse and verify that the plugin's menus, buttons, or features no longer appear in the UI.

##### Example

```
C:\*\eclipse\plugins
/home/usrName/eclipse/plugins
```
