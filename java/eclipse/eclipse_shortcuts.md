# eclipse_shortcuts

### Style #1

The best and most useful shortcuts in Eclipse are categorized as follows:

## Navigation and Opening Files

* Ctrl + Shift + R (or Command + Shift + R on Mac): Quickly open any file or resource in the project by name.
* Ctrl + Shift + T: Open a class or type directly from the workspace.
* Ctrl + 3: Quick Access to any menu, setting, or function in Eclipse.
* F3: Jump directly to the declaration of a variable, function, or class.
* Alt + Left / Alt + Right: Navigate back and forth between locations where you recently edited code. [1, 2, 3, 4]

## Editing and Fixing Code

* Ctrl + 1: Show Quick Fixes and action suggestions when there is an error or warning.
* Ctrl + Space: Automatic code completion (Content Assist).
* Ctrl + Shift + F: Automatically format and organize code.
* Ctrl + D: Immediately delete the current line.
* Alt + Shift + R: Rename a variable, method, or class wherever it appears in the code. [1, 4, 5, 6, 7]

## Comments and Organization

* Ctrl + /: Add or remove a single-line comment (//). * Ctrl + Shift + O: Automatically organize and remove unnecessary imports (Organize Imports).
* Ctrl + O: Show a quick outline (Quick Outline) of the methods and variables in the current class. [1, 8, 9]

| | Step Over (next line) | F6 | F6 |
| | Step Into (enter function) | F5 | F5 |
| | Step Return (exit function) | F7 | F7 |
| | Resume Execution | F8 | F8 |
| Search | Search for File in Project | Ctrl + Shift + R | Cmd + Shift + R |
| | Search for Class/Type | Ctrl + Shift + T | Cmd + Shift + T |
| | Search for Method/Variable in Current File (Outline) | Ctrl + O | Cmd + O |
| | Open Global Search Window (text, code, etc.) | Ctrl + H | Cmd + H |
| Editing & Navigation | Quick Access to any menu/action | Ctrl + 3 | Cmd + 3 |
| | Go to Definition (method/variable) | F3 | F3 |
| | Error correction and Quick Fixes | Ctrl + 1 | Cmd + 1 |
| | Organize Imports | Ctrl + Shift + O | Cmd + Shift + O |
