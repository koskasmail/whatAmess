### declare a `function`

* function must be defined before it is called in Python.
* `def` keyword
    * function is defined using the `def` keyword, followed by a function `name` and `parentheses` ():
    * function name must contain a `snake_case` (lower_case_words)
  
###### 📄 template

