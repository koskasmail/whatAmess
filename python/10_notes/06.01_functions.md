### intro

* a functions is a reusable block of code (sequence) that runs when called.
* a functions is return data.
* a functions helps avoid code repetition.
* a functions is designed to perform a specific task or tasks.

##### Warning
* a functions must be defined before it is called in Python.

### declare

* function must be defined before it is called in Python.
* `def` keyword
    * function is defined using the `def` keyword, followed by a function `name` and `parentheses` ():
    * function name must contain a `snake_case` (lower_case_words)
* function block
    * function block start in 4 spaces characters from the beginning of a new line (a line below 'def' keyword)
  
###### 📄 template: 3 functions 

```python

## functions #1
def greet():
    print("Welcome...");

## functions #2
def _private_function_name():
    print("private...");

## functions #3
def my_calc():
    print("calc...");

```

###### ✏️ example 1: greet functions

```python

###---[function]---###
def greet():
    print("Welcome...");

###---[call function #1]---###
greet();

###---[call function #2]---###
greet();

```


###### 🖥️ output: 

```
Welcome...
Welcome...
```
