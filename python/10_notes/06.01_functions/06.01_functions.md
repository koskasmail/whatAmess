# 06.01_functions

#### functions

```python
def function_name():
    code
```

----

###### ✏️ example: code without function

```python
def greet():
    print("Welcome...");

greet();
print("1");
greet();
print("2");
```


###### 🖥️ output: 

```
Welcome...
1
Welcome...
2
```

----

###### ✏️ example: fahrenheit to celsius

```
def fahrenheit_to_celsius(fahrenheit):
  return (fahrenheit - 32) * 5 / 9

print(fahrenheit_to_celsius(77))
print(fahrenheit_to_celsius(95))
print(fahrenheit_to_celsius(50)) 
```


###### 🖥️ output: 

```
25.0
35.0
10.0
```
