
# ps1_file_shortcut

#### idea
* power shell start at the window folder, and execute a file from local storage or services

### Target --> show terminal
```
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -ExecutionPolicy Bypass -File "file.ps1"
```
### Target --> hide terminal
```
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "file.ps1"
```
